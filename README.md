灵活小鹤音形方案使用说明

之前虽然根据98wubi，整合成了小鹤音形手动造词的方案，但因为rime不能手动调频的关系，一直使用小小输入法平台。小小很好，奈何在win系统中，尤其是在word中，始终有些冲突bug。万象拼音出来后，也使用了一段时间，但还是不习惯拼音串再选字修改的方式，虽然万象已经很方便了。于是又尝试了万象拼音的快捷键调频移植，豆包帮我设置成功了。我的输入法终于可以养老了。

其实也没啥特点，就是终于把自己想要的关键功能凑齐了：能手动造词，能手动调频。主要功能如下。

### 一、造词相关

#### 1. 造词最大词长

在 `flypy.schema.yaml` 中，自动造词最大词长通过 `max_phrase_length` 设置，默认值为4，可自行更改为更高值。

#### 2. 手动造词方法（来自98wubi）

（1）使用单引号 `'` 启用语句流功能实现手动造词，造词时使用单引号 `'` 分词。此为4码造词。2字词：AaAbBaBb。3字词：AaBaCaCb。多字词：AaBaCaZa。

（2）使用波浪符 `~` 启用语句流功能实现手动造词，造词时使用单引号 `'` 分词。此为6码造词。2字词：AaAbBaBbAcBc。3字词：AaBaCaCbAcBc。多字词：AaBaCaZaAcZc。例：时务uiwuow，实务uiwubw。

此模式主要用于重码较多时使用，需注销

  \# max_code_length: 4    （或者不注销此行，将4改为6）
  
  \# auto_clear: max_length

#### 3. 自动造词开启

在 `flypy.schema.yaml` 中设置 `encode_commit_history: true` 开启自动造词；设置为 `false` 则关闭。已生成的自动造词仍会显示（后面带有太极图案），需按 `Ctrl+Del` 手动删除。

默认为手动造词，关闭自动造词。

### 二、特殊功能

#### 4. 万能码 `（波浪号所在的键）和；分号键

小鹤原有功能，按 `（反引号）键可启用万能码模式，用于模糊输入。
；分号键次选，和引导快捷符号。

#### 5. ok引导纯双拼打生僻字

从rime-fast-xhup移植，输入 `ok` 后接纯双拼可输入生僻字，显示拼音和小鹤形码辅助码，例如：

- `oknqnqnq` → 犇 bēn·牛牛

#### 6. 快捷键调频（来自万象拼音）

支持以下快捷键进行词频调整：

- `Ctrl+j`：上移候选词
- `Ctrl+k`：下移候选词
- `Ctrl+l`：重置词频
- `Ctrl+p`：置顶候选词

同时移植了V, R, N键引导计算器、金额大写、和数字转日期功能。

#### 7. 引导输入

（1）输入 `oe` 后可引导输入Emoji表情，例如：

- `oesmile` → 😊
- `oeheart` → ❤️

（2）输入 `oy` 后可引导输入英文单词。

#### 8. 同文trime皮肤（修改于Q主题）

3个皮肤：均无数字首行，1个带底栏，1个不带底栏，1个右手键盘。可以长按字母G键进入编辑键盘，编辑键盘中可以进行调频操作。
