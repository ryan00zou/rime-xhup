灵活小鹤音形方案使用说明

本方案为四码小鹤音形方案，能中英文混输，当字词编码为四码唯一时，自动上屏。不唯一时，则出现次选、英文或emoji表情。

用'键引导造词（编码为4码），例如： 'vif'uie 选择指示上屏以后，输入viui即可出现候选“指示”。

用~键引导造词（编码为6码）。例如： 'vif'uie 选择指示上屏后，输入viuife即可出现候选“指示”。

之前虽然根据98wubi，整合成了小鹤音形手动造词的方案，但因为rime不能手动调频的关系，一直使用小小输入法平台。小小很好，奈何在win系统中，尤其是在word中，始终有些冲突bug。万象拼音出来后，也使用了一段时间，但还是不习惯拼音串再选字修改的方式，虽然万象已经很方便了。于是又尝试了万象拼音的快捷键调频移植，豆包帮我设置成功了。我的输入法终于可以养老了。其实也没啥特点，就是终于把自己想要的关键功能凑齐了：能手动造词，能手动调频。主要功能如下。

### 一、造词相关

#### 1. 造词最大词长

在 `flypy.schema.yaml` 中，自动造词最大词长通过 `max_phrase_length` 设置，默认值为4，可自行更改为更高值。

#### 2. 手动造词方法（来自98wubi）

使用单引号 `'` 启用语句流功能实现手动造词，造词时使用单引号 `'` 分词。

#### 3. 自动造词开启（默认关闭）

在 `flypy.schema.yaml` 中设置 `encode_commit_history: true` 开启自动造词；设置为 `false` 则关闭。已生成的自动造词仍会显示（后面带有太极图案），需按 `Ctrl+Del` 手动删除。

默认关闭自动造词，进行手动造词。

### 二、特殊功能

#### 4. 万能码 `（波浪号所在的键）和；分号键

小鹤原有功能，按 `（反引号）键可启用万能码模式，用于模糊输入。整合了一个4万多字的生僻字反查词库，生僻字也可以第4码用"]"来打，这样就应该不会遇到打不出来的字了。
；分号键次选，和引导快捷符号。

#### 5. ok引导纯双拼部件打生僻字

小鹤原有功能，输入 `ok` 后接纯双拼可输入生僻字，例如：

- `oknqnqnq` → 犇(bēn)

#### 6. 快捷键调频（来自万象拼音）

支持以下快捷键进行词频调整：

- `Ctrl+j`：上移候选词
- `Ctrl+k`：下移候选词
- `Ctrl+l`：重置词频
- `Ctrl+p`：置顶候选词

#### 7. 超级提示（来自万象拼音）

支持单字或重码的2字词组显示emoji提示，增加了英文单词显示emoji提示。按句号“。”键进行选择。
